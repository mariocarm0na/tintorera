# lamejortintorera.com

Web personal de Nuria Chavarría. Página única estática: `index.html` + `robots.txt`, `sitemap.xml`, `llms.txt`, `og-image.png`, `CNAME`.

## Dominios

- **Principal (canónico):** https://lamejortintorera.com — servido por GitHub Pages (`CNAME`).
- **Secundario:** latintoreradetodalavida.com — redirección 301 permanente a https://lamejortintorera.com, configurada en el registrador (no se sirve contenido duplicado).

## Publicar

1. GitHub → Settings → Pages → desplegar desde la rama y carpeta raíz. Custom domain: `lamejortintorera.com`, activar "Enforce HTTPS".
2. DNS de lamejortintorera.com: registros A a 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153 y CNAME `www` → `<usuario>.github.io`.
3. latintoreradetodalavida.com: reenvío web 301 (permanente) a https://lamejortintorera.com, con y sin `www`.
4. Google Search Console y Bing Webmaster Tools: verificar ambos dominios y enviar `https://lamejortintorera.com/sitemap.xml`.

Pendiente: sustituir los textos entre [corchetes] (ciudad, contacto, trayectoria).
