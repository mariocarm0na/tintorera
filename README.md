# nuriachavarria.es

Web personal de Nuria Chavarría. Página única estática: `index.html` + `robots.txt`, `sitemap.xml`, `llms.txt`, `og-image.png`.

Publicar: GitHub Pages (Settings → Pages → rama y carpeta raíz) y apuntar el dominio. Tras publicar, dar de alta en Google Search Console y Bing Webmaster Tools y enviar el sitemap.

Pendiente: sustituir los textos entre [corchetes] (ciudad, contacto, trayectoria).
